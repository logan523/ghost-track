# NASA 3D spacecraft models

Vendored from [NASA 3D Resources](https://github.com/nasa/NASA-3D-Resources).

NASA states these assets are free to download and use. See
https://www.nasa.gov/nasa-brand-center/images-and-media/

| File | Source folder |
|------|----------------|
| `iss.glb` | International Space Station (ISS) (B) |
| `hubble.glb` | Hubble Space Telescope (A) |
| `landsat.glb` | Landsat 7 |
| `cloudsat.glb` | CloudSat (A) |
| `cubesat.glb` | CubeSat - 1 RU Generic |

Used as 3D globe markers in Orbit Ghost. Not claimed as original artwork.
